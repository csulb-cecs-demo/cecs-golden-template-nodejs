# Docs

Faculty guidance for adapting this Node.js golden template for a course.

The [template README](../README.md) covers the project layout, API, and local
commands. The [sample assignment](assignment.md) describes the exercise
contract. [Governance](governance.md) explains the recommended repository
baseline.

Replace the sample assignment with your own course instructions when adapting
the template. Keep a real test suite and a workflow on push or pull request so
students receive quick feedback.
